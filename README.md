# 🖧 Computer Networking Lab Practice (Packet Tracer)

This repository contains **Cisco Packet Tracer (.pkt) lab practice files** focused on core networking concepts taught in **Computer Networking** courses.  
All labs are designed for **academic learning, exam preparation, and hands-on practice**.

---

## 📘 Lab Topics Covered

### 🔹 Static Routing
- Basic static route configuration
- Manual route management
- Small to medium network design

📁 Files:
- `STATIC.pkt`
- `Simple Company STATIC.pkt`

---

### 🔹 Dynamic Routing (RIP)
- RIP (Routing Information Protocol) configuration
- Automatic route advertisement
- Multi-router network communication

📁 Files:
- `RIP.pkt`

---

### 🔹 DHCP (Dynamic Host Configuration Protocol)
- Automatic IP address assignment
- DHCP server and client configuration
- Reduced manual IP configuration

📁 Files:
- `Simple company DHCP.pkt`

---

### 🔹 Combined Practice (Static + DHCP + RIP)
- Hybrid network design
- Realistic company-level network simulation
- Integration of multiple networking concepts

📁 Files:
- `ALL3-static,dhcp,rip.pkt`
- `Lab5.pkt`

---

## 🎯 Learning Outcomes

- Understand **IP addressing and routing**
- Configure **Static Routing and RIP**
- Implement **DHCP for automated networking**
- Design **simple company-level networks**
- Gain confidence in **Packet Tracer simulations**

---

## 🛠 Tools Used
- **Cisco Packet Tracer**
- **TCP/IP Protocol Suite**
- **RIP (Distance Vector Routing Protocol)**
